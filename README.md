## What is NASA?
This is a course by NTU CSIE, course topics include "Network Administration" and "System Administration". 
You will learn A LOT after this course, hands-on training account for about 70%.
Network Administration(W1-8) teaches IP/Cable/Switches/VLAN, LVM/RAID/Partition/Disk, Permission/Unix/Shell scripting (i hate this it's so hard), Firewall , DHCP/VPN/NAT/DNS, Web Server, and more.
System Administration(W9-16) teaches Docker/VM, LDAP/Kernel, NFS, Wireless stuff, Security, and more.

## Prerequisites?
No, but a bit of linux familiarity would be nice.
Oh by the way there is HW0 todo even when the semester is not started :), but if you finish it on time and made sure answers are correct then most likely you can enroll in this course.

## Difficulty?
If you enjoy sitting infront of the terminal 8-10 hours a week (even with AI assistance), or just like this topic, you are very welcomed to take this course.
13 homeworks, 14 labs, 25+ in-class problems, 2 exams.
Exams are hard but depends on if teaching team allows GenAI usage. Before, students usually only average 30 points / 200 points.
